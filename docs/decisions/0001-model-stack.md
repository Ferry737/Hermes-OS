# تصمیم ۰۰۱: کدام framework و کدام مدل‌ها برای Hermes OS

تاریخ: 2026-10-11 · وضعیت: پیشنهاد (منتظر تأیید Ferry)

## خلاصه در ۵ خط

1. **Framework:** همان **Hermes Agent** که الان روی VPS نصب است. Dify و OpenClaw نه (دلیل پایین).
2. **مدل روزمره (رایگان):** **OpenRouter** با یک بار شارژ ۱۰ دلار (سقف رایگان از ۵۰ به ۱۰۰۰ درخواست در روز می‌رود) + **Groq** رایگان به عنوان پشتیبان.
3. **کار سخت:** **Claude Code** روی VPS (`claude -p`)، که از اعتبار ماهانه‌ی agent در اشتراک Claude کم می‌کند. نه وصل کردن مستقیم اشتراک به Hermes.
4. **حقیقت تلخ:** رایگان برای «۱۰ تیم ۲۴ ساعته» کافی نیست. ظرفیت واقعی رایگان حدود ۴۰ تا ۱۰۰ کار کوچک در روز است. برای بیشتر، باید یک مدل ارزان پولی اضافه شود.
5. **امنیت:** هیچ کلید صرافی، کلید خصوصی کیف پول یا اطلاعات شخصی هرگز به مدل رایگان نمی‌رود.

## ۱. Framework: چرا Hermes Agent

| گزینه | حکم | دلیل |
|---|---|---|
| **Hermes Agent** (NousResearch) | ✅ انتخاب | از قبل روی VPS است، gateway آن روی `127.0.0.1:8642` تست شده (branch `orchestra-build`)، داشبورد، cron، skills و memory دارد، و از چند provider با fallback پشتیبانی می‌کند. طرح Cockpit هم روی همین ساخته شده. |
| **Dify** | ⏸ بعداً، فقط برای Agency | Dify برای ساختن workflow و اپ برای **مشتری** قوی‌تر است، نه برای agent خودمختار شخصی. وقتی Agency مشتری واقعی داشت، دوباره بررسی شود. |
| **OpenClaw** | ❌ نه | Anthropic از ۴ آوریل ۲۰۲۶ دسترسی ابزارهای third-party مثل OpenClaw به اشتراک Claude را قطع کرد، و سابقه‌ی امنیتی‌اش هم خوب نیست. |

**حقیقت تلخ:** عوض کردن framework الان یعنی برنامه‌ریزی سوم، بدون هیچ چیزِ shipشده. مشکل اصلی پروژه framework نیست؛ این است که هنوز هیچ agentی کار واقعی انجام نمی‌دهد.

## ۲. مدل‌های رایگان: اعداد واقعی (بررسی‌شده 2026-10-11)

| Provider | سقف رایگان | مدل‌های مفید | ریسک داده | نقش |
|---|---|---|---|---|
| **OpenRouter** `:free` | ۲۰ درخواست/دقیقه؛ **۵۰/روز** بدون خرید، **۱۰۰۰/روز** بعد از خرید ۱۰ دلار اعتبار (یک بار) | ۲۰+ مدل باز | بسته به provider؛ `data_collection: deny` بگذارید (ممکن است بعضی مدل‌های رایگان را حذف کند، تست نشده) | **اصلی** |
| **Groq** | ۳۰/دقیقه، ۱۰۰۰/روز، ولی فقط **۲۰۰ هزار توکن در روز** برای هر مدل | `gpt-oss-120b`، `qwen3.8-27b`، `whisper` (برای صدای داشبورد) | آموزش روی داده نه | **پشتیبان سریع + تبدیل صدا به متن** |
| **Google Gemini** رایگان | Google دیگر سقف را منتشر نمی‌کند؛ Flash در دسامبر ۲۰۲۵ به ۵/دقیقه و ۲۰/روز کم شد | Gemini Flash | داده برای آموزش استفاده می‌شود و ممکن است انسان بخواند. **طبق شرایط، اپ‌هایی که به کاربر در سوئیس/EU/UK سرویس می‌دهند فقط tier پولی مجازند** | ❌ استفاده نکنید (تا شرایط برای سوئیس دقیق چک شود) |
| **Cerebras** | دیگر رایگان دائمی نیست: ۵ دلار اعتبار آزمایشی، کارت بانکی لازم، بعد ۳۰ روز تمام | gpt-oss-120b | — | ❌ ارزش ندارد |

### حساب ظرفیت (حقیقت تلخ)

- یک «کار» agent (مثلاً تحقیق و خلاصه‌ی یک موضوع) معمولاً **۱۰ تا ۳۰ درخواست** به مدل است (فکر، ابزار، دوباره فکر).
- Groq: ۲۰۰ هزار توکن در روز ÷ حدود ۵ هزار توکن هر درخواست ≈ **فقط ۴۰ درخواست در روز** برای هر مدل.
- OpenRouter: ۱۰۰۰ درخواست در روز، ولی مدل‌های رایگان گاهی کند یا در صف هستند.
- **جمع: حدود ۱۱۰۰ درخواست در روز ≈ ۴۰ تا ۱۰۰ کار کوچک در روز.**
- «۱۰ تیم، ۲۴ ساعته» با فقط ۵ کار در ساعت برای هر تیم ≈ ۱۸ هزار درخواست در روز. یعنی **رایگان حدود ۱۵ برابر کم است.**

نتیجه: با رایگان شروع کنید و **یک تیم** را واقعاً کارا کنید. وقتی آن تیم پول یا ارزش ثابت ساخت، یک مدل ارزان پولی روی OpenRouter اضافه کنید (هزینه را بعداً با مصرف واقعی اندازه می‌گیریم؛ قیمت‌ها در این سند بررسی نشده‌اند).

## ۳. کی به مدل frontier (Claude) برویم

قانون Anthropic (تأییدشده): از فوریه ۲۰۲۶ توکن OAuth اشتراک فقط برای ابزارهای رسمی (claude.ai و Claude Code) است، و از **۴ آوریل ۲۰۲۶** اجرا می‌شود. از **۱۵ ژوئن ۲۰۲۶**، `claude -p` و Agent SDK از اعتبار ماهانه‌ی جداگانه کم می‌کنند (Pro: ۲۰ دلار، Max 5x: ۱۰۰ دلار، Max 20x: ۲۰۰ دلار، با قیمت API). Claude Code تعاملی (خودتان در ترمینال) هنوز از سقف اشتراک استفاده می‌کند.

پس:
- **هرگز** اشتراک Claude را با login مستقیم به Hermes وصل نکنید. خلاف شرایط است و ممکن است حساب بسته شود.
- Hermes کار سخت را با اجرای `claude -p` روی VPS (ابزار رسمی) می‌فرستد. هزینه از اعتبار ماهانه‌ی agent کم می‌شود. وقتی تمام شد، **متوقف شود** (usage credits اضافه را فعال نکنید).

**به Claude بفرست وقتی:**
1. ریاضی معاملات: منطق استراتژی، اندازه‌ی پوزیشن، ریسک ۲٪، تحلیل backtest.
2. هر کدی که به پول، کلید، کیف پول یا سفارش واقعی دست می‌زند.
3. تصمیم‌های معماری و هر چیزی که به مشتری تحویل می‌شود (بررسی نهایی).
4. مدل رایگان **دو بار پشت سر هم** در یک کار شکست خورد.

**روی رایگان بماند:** جمع‌آوری تحقیق، خلاصه، پیش‌نویس، دسته‌بندی، کد boilerplate، گزارش روزانه، عنوان و فشرده‌سازی متن.

## ۴. امنیت (مهم‌ترین بخش)

- **دو آسیب‌پذیری باز در Hermes Agent:** CVE-2026-9353 (در Skills Guard) و CVE-2026-10220 (در skills tool)، هر دو injection، شدت متوسط، کد exploit عمومی، و **طبق منابع بررسی‌شده هنوز patch رسمی ندارند.** پس:
  - هیچ skill یا plugin از منبع ناشناس نصب نکنید.
  - Hermes را با کاربر غیر root (و ترجیحاً در Docker) اجرا کنید و نسخه را pin کنید.
- **شبکه:** همان قانون قبلی: فقط tailnet، هیچ tunnel عمومی (بعد از حادثه‌ی ۲۴ سپتامبر).
- **داده به مدل رایگان:** هیچ کلید API صرافی، کلید خصوصی کیف پول، seed phrase، اطلاعات حساب prop firm یا اطلاعات شخصی/مشتری به مدل رایگان نرود. فرض کنید هر چیزی که به مدل رایگان می‌رود ممکن است ذخیره یا خوانده شود.
- **کلیدها:** در `~/.hermes/.env` با دسترسی `600`، هرگز در git. کلید صرافی فقط **read-only یا trade بدون withdraw**.
- **Prompt injection:** داده‌ی وب، توییت و قرارداد DeFi می‌تواند دستور مخفی داشته باشد. agentی که وب می‌خواند **نباید** هم‌زمان اجازه‌ی معامله یا ارسال پول داشته باشد.
- **سقف هزینه:** `ops/gates/budget.sh` فعال بماند. اعتبار OpenRouter را auto-top-up نکنید.

## ۶. config پیشنهادی (طرح، روی VPS تست نشده)

```yaml
# ~/.hermes/config.yaml  (key names from the OpenRouter Hermes guide; verify against your installed version)
model:
  provider: openrouter
  default: <a :free model, pick after a 1-day trial>
fallback_providers:
  - { provider: groq, model: openai/gpt-oss-120b }
provider_routing:
  data_collection: deny
auxiliary:
  title: groq/openai/gpt-oss-20b
  compression: groq/openai/gpt-oss-20b
```
